# Student Record Management System

## Objective
A CLI-based Java application for managing student records.

## Features
- Add Student
- View Students
- Update Student
- Delete Student
- Exit

## Technologies Used
- Java
- ArrayList
- OOP
- Encapsulation

## Concepts Used
- Classes and Objects
- ArrayList
- Loops
- Getters and Setters
- Constructors

## How to Run

Compile:
javac Student.java StudentManagementSystem.java

Run:
java StudentManagementSystem
